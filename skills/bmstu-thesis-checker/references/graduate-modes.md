# 硕士与博士模式：已验证范围

使用 `check_thesis_document` 或命令行检查时，硕士传 `work_type=master`，博士科研资格论文传 `work_type=phd`。博士对应原程序按钮 **НКР аспиранта**，不等同于所有学校的博士学位论文标准。

原始截图、输入哈希、输出及对照矩阵在插件根目录的 `evidence/graduate-structure/`；`summary.json` 是证据入口。以下是 build 230、普通正文段落 DOCX 的有限样例验证。带表格、图片、域、文本框、内容控件或修订的文档不会继承这批结构规则的高置信验证状态。此处结构规则的 PDF 等价性未验证；部分 PDF 格式谓词另见 format-expansion.md。

## 硕士原样例剩余六条诊断

- 校名错误：简写 `МГТУ им. Н. Э. Баумана` 不足以匹配内置 TITUL 模板；应按真实学校封面填入完整校名及相关单位名称。
- 封面多处不匹配：原样例缺少主管机构、院系、题目、指导教师、规范审核等模板内容。补全真实信息；姓名、签字和题目不能自动编造。
- 附录标题缺失：该样例被要求提供 `ПРИЛОЖЕНИЕ А`。这一行为不代表每篇真实论文都应添加空附录；核对模板和论文内容。
- 目录被判空：原目录只有四条可识别的带页码条目。4条会命中“空”；5—10条会命中“过短”；11条起不再命中这两项。应更新真实目录，不为凑条目拆分无意义小节。
- 摘要过短：原摘要只有一个非空段落。恢复逻辑还检查俄语字符量；三个实质段落的对照样例消除了该提示。350俄语字符的精确边界来自静态逻辑，尚未做独立边界动态验证，不能当学校写作要求。
- 篇幅不足：该模式阈值为48“折算页”，每页按900字符计算，同时检查目录中附录A的页码。计数从摘要标题开始，到附录标题之前结束，各段去首尾空白，按UTF-16单位计数。43199／43200字符及附录A页码47／48的两对边界已实测。Word缓存页数47／48不影响结果。这不是实际排版页数，也不是60000字符的旧本地阈值。带图表时的补偿算法尚未验证。

## 博士科研资格论文

- 目录标题要求 `ОГЛАВЛЕНИЕ`；使用 `СОДЕРЖАНИЕ` 会连带导致目录、主章节和目录一致性提示。
- 工作名称按 `НАУЧНО-КВАЛИФИКАЦИОННАЯ РАБОТА` 检查；封面身份为 `Аспирант`／`Аспирантка`。内置校名和封面模板同样需要核对。
- 原程序该分支没有选择硕士使用的数字篇幅下限；本地 DOCX 不再套用旧的100000字符猜测。不能因此声称真实博士论文没有篇幅要求。
- 修正博士样例的封面和目录后，剩余页边距警告。单独把右边距改成15毫米未清除；只把左边距从30毫米改为25毫米（右／上／下仍为10／20／20毫米）后，原程序显示无意见。该单变量样例已验证，原始DOCX只有左边距属性改变；本轮后续对照已确认容差为±0.2毫米，四边目标为左25、右10、上20、下20毫米，详见 format-expansion.md。暂不自动修改博士边距。

这批规则用于诊断和人工修订指导，不增加封面、结构、篇幅或目录页码的自动改写。已有副本自动修复仍限已验证的本科／硕士普通字号、颜色和A4纸张。

当前博士副本修复范围以 [多页与博士修复](multipage-phd-repair.md) 为准；本文件早期未开放记录为历史结果。
