# 版本演进

当前发布版本：v0.2.13；插件版本0.2.13+codex.20261015；MCP协议返回版本0.2.13。

v0.2.13：15个原程序绘图输入确认面积/环绕、文本框尺寸/数量与四条报告链；纠正普通小字等误报，新增定位和限定配置验证。保留分析伪代码及旧槽命名纠正，未知环绕保持未判定，不开放绘图自动修复。[发布说明](../releases/v0.2.13.md)

v0.2.12：五个原生ZIP大小对照确认逐图片本地头字段>30000000，而文案仍40Mb；修正232 DOCX本地累计模型，新增源条目定位与博士受测上下文验证。ZIP64等未验证输入保持待复核。[发布说明](../releases/v0.2.12.md)

v0.2.11：图片业务函数地图、6个真实原生像素边界、标志/报告计数、同输入代码页因果对照、PDF对象去重；仅博士受测PNG配置获得232版本检测证据。其他规则与修复范围不扩大。[发布说明](../releases/v0.2.11.md)

v0.2.10：后台原生入口开放硕士/博士NKR DOCX/PDF，12个合成案例有实际加载器、模式码、选择阈值、正常返回及完整报告证据。多页PDF结构反例和复杂DOCX均已运行；保留图片单位乱码差异，修复权限不扩大。[发布说明](../releases/v0.2.10.md)

v0.2.9：恢复此前超时的主检查函数，定位并受控修正中文系统上的俄语词库/模板解码；新增原生对照 CLI 和第十个 MCP 工具。四组硕士篇幅边界有实际分支证据，复杂 DOCX 的13条诊断匹配已有俄语环境记录。依赖原 EXE，限Windows硕士DOCX；独立引擎验证状态和修复范围不扩大。[发布说明](../releases/v0.2.9.md)

v0.2.8：164条逐项源事实复核、特殊角色/校名/行高建议分流；新版硕士普通正文字号一项修复独立验收开放，含原程序/XML/CLI Word版面证据。学校合规未确证，其他新版修复动作仍关闭。[发布说明](../releases/v0.2.8.md)

v0.2.7：298条原复核记录逐项生成证据处置，13条名称识别误报修正；17案例218→205候选；后台JSON CLI、修改资格字段、新版真实反编译伪代码及两组字号修复前后对照。仍未完成全部学校合规判定，新版副本修复未开放。详见[发布说明](../releases/v0.2.7.md)。
