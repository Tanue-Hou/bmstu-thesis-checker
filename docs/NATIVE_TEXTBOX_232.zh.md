# 原生232文本框：单位、样式层和分支

在上一轮15个绘图输入之外，本轮增加32个实际原程序DOCX/NKR输入。审计逐项比较原生尺寸、宽/高分支命中、计数和独立检查结果，输入和追踪器均有哈希。不是学校规范或全部图形等价证明。

0041a204通过`%f%c%c`读取float32数值与单位，再乘原生float32常数并回存。mm和无单位在受测路径保持原值，cm乘10、pt乘0.35277777910232544、in乘25.399999618530273；三种单位及无单位各有低于/等于/高于2mm边界，等值均不触发。每次先舍入输入float32，再乘已舍入常数，再舍入结果。

静态还确认pc乘4.233333110809326、px乘0.0027600000612437725。px单例3.779527559px实际得到0.010431496426463127，不能按通常屏幕DPI解释；独立引擎保留原生换算候选，但px缺少负例/等值边界、pc缺动态证据，均不获得已验证状态。

| 单因素输入 | 原生观测 |
|---|---|
| shape样式`mso-fit-shape-to-text:t/true`，5×1mm | 自适应位生效，有效高度变为10mm，小框计数0 |
| shape同样设置，1×5mm | 宽度仍1mm，小框计数11 |
| shape设置false，5×1mm | 小高度分支仍命中，计数11 |
| textbox层设置t/true/false | 本轮同输入未设置自适应位，小高度仍计入；不能把两层设置合并 |
| inset全零或四项2mm | 本轮几何与计数相同；不能推广到任意内边距 |
| 空文本、长文本、1×50或50×1mm | 本轮三类诊断与原生一致，不据此认定渲染或遮挡行为相同 |
