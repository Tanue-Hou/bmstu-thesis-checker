# v0.2.7 · 误报修正与后台接口

真实案例的俄语变格封面被本地误判为工作名称错误。本版修正这个识别缺陷，17案例重跑从218降到205候选组，移除的13组均为该缺陷，原件保持不变。

原298条记录逐项保留证据处置：13条确认本地识别缺陷、47条模式不适用、32条参考适用性未确认、29条提示候选、13条前置页特殊角色、164条仍需条款/源属性/页面复核。处置不是最终学校合规裁决，不公布准确率；私人记录与论文均不上传。

- 后台 JSON CLI：check / review / plan / apply；执行修复前核对输入哈希和计划ID。
- MCP/Skill返回独立的action_eligibility，避免检测候选直接变成改写指令。
- 新版真实反编译C风格伪代码及函数/调用索引：10191/10192个已发现函数导出成功，含运行库，无法视为完整原始工程。
- 新版两组匿名硕士正文异常字号副本修复前后对照通过，其他原诊断和文档文字保持；尚无复杂布局/特殊内容保护的完整新版验证，故新版修复仍关闭。
